# Rent sharing: MVP implementation plan

This plan follows the [product brief](rent-sharing-brief.md). The MVP is a responsive website with browser-local records, no login, full data export/import, an interactive Sankey diagram, and a dated chart image export. Wen brings firsthand rent-sharing expertise and leads design. Jonathan leads marketing, cost management, delivery coordination, and web development. The team can launch and iterate without a prelaunch review gate.

The MVP covers the monthly rent flow only. It excludes payment-chasing and other reminders, ad hoc splits for meals or gatherings, and expenses on a different or nonmonthly billing cycle (for example, quarterly electricity or water billed every two months).

## Launch checks

- Verify that individual and “Others” Sankey totals reconcile to the rent total and recorded contributions. Collapsing branches must not change saved data.
- Verify the equivalent text view, keyboard expansion, small-screen layout, and static image readability without interaction.
- Export complete data, import it into a fresh browser, and check that household, months, shares, and contributions match. Test invalid files and an import conflict.
- Explain local-only storage and backups where users first save data and where they export it.
- Check the chosen money-flow rules against partial payments, corrections, refunds, and edited shares.

These are implementation checks, not a required team approval before launch. Jonathan and Wen can publish the web MVP and use live feedback for subsequent iterations. Wen makes the final product-scope decision when tradeoffs arise.
